# Z's Multi Tool

Z's Multi Tool is a powerful all-in-one desktop utility designed to bring essential tools and system management features into a single application. Whether you're managing games, monitoring system performance, handling files, or working with development utilities, Z's Multi Tool provides a centralized workspace for everything you need.

## Features

### Game Manager

The Game Manager allows users to organize and manage their game library with ease.

* Add custom game profiles
* Store game save locations
* Configure backup save locations
* Manage multiple games from a single interface

### Application Launcher

Launch any executable directly from the tool.

* Add custom EXE files
* Organize applications
* Quick-launch games and programs

### Music Player

Built-in music playback and management.

* Play local music files
* Music downloading tab
* Discord Rich Presence integration showing currently playing music

### File Utilities

Advanced file management and security tools.

* File encryption
* File decryption
* Secure file shredding
* Protect sensitive data from unauthorized access

### Notes Module

Simple and lightweight note-taking system.

* Create and edit notes
* Save notes as .txt files
* Quick access for reminders and documentation

### System Monitor

Monitor your computer's performance in real time.

* CPU usage
* Memory usage
* CPU core utilization
* Disk drive information
* Storage statistics
* Network adapter details
* Operating system information

### Process Manager

Manage running applications and processes.

* View active processes
* End unresponsive programs
* Monitor resource usage

### Hash Checker

Verify file integrity using multiple hashing algorithms.

Supported algorithms:

* MD5
* SHA1
* SHA224
* SHA256
* SHA512

### Developer Utilities

#### JSON Formatter

Format and validate JSON data for easier reading and editing.

#### XML Formatter

Format and organize XML files.

#### CSV Viewer & Editor

Open, view, and edit CSV files directly within the application.

### Discord Integration

Built-in Discord Rich Presence support.

* Displays the module currently in use
* Shows music currently being played
* Displays operating system information
* Share activity with friends automatically

## Goal

Z's Multi Tool aims to eliminate the need for multiple separate applications by combining game management, file utilities, system monitoring, media playback, and developer tools into one easy-to-use platform.
